# CRCR Mockup Catalogue

The HTML files in this directory are design explorations for the CRCR surfaces
implemented in PyTorch CI HUD. They are static prototypes: they illustrate
information hierarchy and interaction intent, not a production data source.

## Browse by question

|---|---|

| What did a partner report? | [nightly run inspector](crcr-nightly-run-inspector-mockup.html), [failed-job drilldown](crcr-failed-job-drilldown-mockup.html), [artifact browser](crcr-artifact-browser-mockup.html) |
| Can a partner be promoted or demoted? | [onboarding progress](crcr-onboarding-progress-mockup.html), [tier readiness](crcr-tier-readiness-mockup.html), [promotion review](crcr-promotion-review-mockup.html), [level history](crcr-level-history-mockup.html) |
