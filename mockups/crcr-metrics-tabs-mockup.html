Implementation Notes
  • New ClickHouse query: crcr_nightly_success_rate — same structure as crcr_success_rate but filters event_type = 'nightly' instead of pr_number > 0
  • Tab state: useState<'pr' | 'nightly'>('pr') — controls which data to fetch and display
  • Charts reused: PassRateChart, FailuresChart, TotalRunsChart accept data as props — no changes needed to chart components
  • Data fetching: Both PR and nightly data can be fetched in parallel via useSWR; only the active tab's charts render
  • Repos list: Each tab shows its own set of repos derived from the active dataset
